# 出典一覧（関西電力 公式サイト）

本アプリの問題は、以下の関西電力公式サイト（kepco.co.jp）内の公開情報を出典として作成しています。
テーマごとに一次資料へのリンクを整理しました。学習の際の原典確認にご利用ください。

> 注記: URLは2026年7月時点で確認したものです。公式サイトのリニューアルやファイル名変更によりリンク切れが生じる場合があります。その際は各テーマのトップページから辿ってください。

| `keiei2026` | 経営計画2026 | https://www.kepco.co.jp/corporate/policy/pdf/plan_2026.pdf |
| `report2025` | 統合報告書2025 | https://www.kepco.co.jp/corporate/report/integrated/ |
| `kessan2025` | 2025年度決算説明資料 | https://www.kepco.co.jp/ir/brief/earnings/2026/pdf/pdf2026_04_05.pdf |
| `governance` | コーポレートガバナンス・ガイドライン | https://www.kepco.co.jp/ir/policy/governance/images/pdf/corporate_governance_guideline.pdf |
| `conduct` | 関西電力グループ行動憲章 | https://www.kepco.co.jp/corporate/policy/charter/index.html |
| `zerocarbon_vision` | ゼロカーボンビジョン2050 | https://www.kepco.co.jp/sustainability/environment/zerocarbon/index.html |
| `zerocarbon_roadmap` | ゼロカーボンロードマップ | https://www.kepco.co.jp/sustainability/environment/zerocarbon/roadmap.html |
